# Shape Shifter Curse: Primalstinct

## Introduction

The official addon of [Shape Shifter Curse](https://github.com/onixary/shape-shifter-curse-fabric): adds gameplay centered on **instinct control** for feral forms. As your **Primal Instinct** progresses, you will be granted greater power.. at only a ***tiny***, negligible cost. Will you answer the call of the Primalstinct?
