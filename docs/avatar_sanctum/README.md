# 原始之神的裂缝维度 · 固定场景 v3

直接编写的 Java 1.20.1 结构模板：`data/ssc-primalstinct/structures/avatar_sanctum.nbt`。
模板外框145×152×145格，实际建筑占地更小；325040个非空气方块，压缩约0.96 MiB。没有打包生物或动画实体。结构大小超过原版结构方块编辑UI上限，通过现有代码的StructureTemplate加载，不受该UI限制。

## 场景构图

- 12根外围圆形石柱，半径4—10格，柱顶Y=91—111。出生柱半径10、柱顶95；中央柱半径19、柱顶107。
- 所有柱体延伸至维度底部Y=0，没有可行走的底层地板。石柱的暗部、虚空与高度差构成深渊感；实际雾效和可见度由客户端决定。
- 中央柱东侧近半坍塌，只有下部断面及零星坠落石块。上方有残存的圆弧巨石梁、矩形立柱与环形铺地，转化台在中心。
- 出生柱到中央柱约52格。残桥有连续三格宽阶梯主线，旁侧桥面、护栏、桥底破损；无需跳跃跨越断桥。其他桥只剩两端，自动检查确认无法连续步行通往外围柱顶。
- 多根柱体有矩形贯穿孔。石材采用石头、凝灰岩、安山岩、石砖、裂石砖和苔石砖，配大块连续潮湿斑、建筑水平分层与破碎压顶。
- 蔓藤垂挂于柱壁、残梁与断面，地面有小片苔藓、蕨类和持久树叶。少量海晶灯沿出生点、残桥、中央转化台排列。
- 三条大型石质触须从坍塌下部向上弯曲，使用深板岩、黑石、玄武岩与少量暗海晶石矿化纹理。顶部留给后续小型动画触须模型。

## 载入与旧场景

AvatarSanctum现在从NBT固定加载，不再在Java里搭17×17占位平台。尺寸、唯一转化台与9个门面的坐标会先验证，成功放置后才标记v3完成；再次进入不重建。

安装新jar并重新启动游戏后，首次进入该维度或使用原有`/primalstinct debug endgame sanctum`命令会触发初始化/版本升级（需管理员权限）。

旧v1/v2的17×17平台只清理已知占位材料和功能方块的原区域，随后新石柱覆盖该位置。旧平台上的在线玩家和重登玩家被安置到新出生点。不会清空整个维度，也不会删除维度存档。新场景本身占地内的建筑会被模板覆盖。

整个场景首次同步放置约32.5万方块，会有一次性加载开销，尚未实测游戏内耗时。后续进入只检查完成标记。
