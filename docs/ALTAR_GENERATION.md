# 原初祭坛生成与激活展示

## 生成位置

`PrimalAltarStructure` 在创建 structure start 前，按照实际 NBT 模板对齐祭坛后得到的完整包围盒检查占地。使用生成器的列采样检查每一列地表及模板放置高度范围内的流体，拒绝水面、岸边部分跨水以及模板体积内的水/熔岩。不读取或强制加载邻接完整区块。缺少模板时同样检查内置回退布局。

此判定针对世界生成器提供的地形采样；后续模组地物或玩家引水不属于生成选址控制范围。

## 密度

配置：`data/ssc-primalstinct/worldgen/structure_set/primal_altar.json`。

- spacing：90 区块（1440 格的候选网格）。
- separation：45 区块。
- salt 保持原值。
- 与上一版 spacing=128 相比，单位面积候选数为 (128/90)² ≈ 2.02 倍；separation 同比例缩小。

上一版 spacing=128 的玩家实测：祭坛距出生点约2000—4000格，因此按反馈将候选密度提高约两倍。候选密度按 spacing 的平方反比调整，密度翻倍不代表距离减半；真实距离仍受种子、海陆分布与完整模板占地的流体筛选影响，本版距离待游戏实测。

只对新生成的结构起点生效，已有存档中的祭坛不会删除或移动。测试请新建世界或探索未生成地区。

## 激活表现

- 服务端仅在 ACTIVE 从 false 变成 true 时广播祭坛中心的末地烛粒子环、附魔粒子和信标激活音效。
- 客户端 `PrimalAltarRenderer` 在 ACTIVE 时渲染镇静碎片物品模型，使用满亮度、慢速旋转和轻微上下浮动。
- 该显示不是 ItemEntity，不可提前拾取；领取仍走原有右键事务。断电或替换为失效祭坛后不再显示。
- 客户端渲染只读取同步的方块 ACTIVE 状态，不需要将献祭绑定数据同步给客户端。

## 验证

已执行 `gradlew.bat test build`。游戏内补充检查：新世界海岸/河流/高处湖泊选址；三路导线激活时播放一次特效；反复重算不重复播放；断线重连看到碎片但不重播激活；断电隐藏、重新接通显示；领取后只有实际奖励掉落且祭坛上方预览消失。
