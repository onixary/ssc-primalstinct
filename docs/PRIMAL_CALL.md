# 原始呼唤

形态进入 `primalstinct/forms` 有效名单不再自动接管 SSC 本能系统。玩家需要让 `ssc-primalstinct:primal_call` 自然到期，之后才会接管本能条、增长和等级能力。开局选择形态同样需要呼唤。

- 未觉醒的名单形态击杀 `MobEntity`（包括动物和怪物，不包括玩家、盔甲架）默认有 1% 概率获得 60 秒呼唤，归属玩家的远程击杀也适用。
- 使用 `ssc-primalstinct:primal_instinct_fang` 必定尝试施加呼唤。成功才消耗一个，创造模式不消耗；已有呼唤或已觉醒时不能重复使用。
- 无序合成：骨头、回响碎片、`shape-shifter-curse:untreated_moondust`、红石各一个，产出一枚牙。物品在附属创造标签页中可用。
- 获取时聊天提示；自然结束时聊天提示，并复用普通升阶的 1 秒黑暗、5 秒恶心效果。
- 牛奶、命令清除、死亡移除不会觉醒。真实切换形态取消呼唤，同形态重载不取消。无限时长效果不会自然到期。
- 命令等外部施加同样受服务端形态资格检查限制。Buff 随原版状态效果保存，离线不倒计时。
- 觉醒标记是玩家级永久状态，死亡和重登保留；离开名单形态暂停接管，回到名单形态继续。喝奶只取消尚未完成的呼唤，不撤销已经完成的觉醒。
- 旧存档没有觉醒标记，需要完成一次呼唤；已有本能数值和锁定状态保留，觉醒后继续原进度。

配置 `config/ssc-primalstinct-server.json`：`primal_call_kill_chance` 默认 `0.01`（0 禁用击杀触发），`primal_call_duration_seconds` 默认 `60`，重进世界或重启服务端生效。

实机检查建议：未觉醒名单形态仍显示并运行 SSC 本能；用牙后喝奶应恢复无 Buff 状态且不接管；再次用牙等待结束应提示并接管；测试不支持形态、重复使用、切形态、死亡和带 Buff 重登。可用 `/effect give @s ssc-primalstinct:primal_call 3` 缩短到期测试。

视觉资源目前复用原版骨头和回响碎片的叠层物品模型，以及本能过热的状态图标。
